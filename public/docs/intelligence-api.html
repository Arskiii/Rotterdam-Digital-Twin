Data and methods

All public endpoints are read-only JSON. The Pages deployment is static. A separately hosted observation receiver can provide current readings when configured. The response fields are inspired by OGC SensorThings terms such as observation time and datastream; this is a documented subset, not an assertion of OGC conformance.

Public files

  • /api/v1/catalog.json — source, access, licence and limits
  • /data/exposure.json — sampled road exposure to Rotterdam's modelled >25 cm water surface
  • /data/cbs-neighborhoods.json — released, aggregated CBS neighborhood totals
  • /data/live/live.json — packaged fallback snapshot, often old

Each response includes a schema version or an observation timestamp. Missing readings are absent or null. The source catalog records availability and known limits. The intelligence page displays current ages and counts.

Optional current observation receiver

Run npm run start:observations on a persistent HTTPS host with OBSERVATION_INGEST_TOKEN (at least 32 characters), OBSERVATION_READ_ORIGIN (the exact public site origin), and OBSERVATION_STORE_PATH (a writable absolute file). Publish only approved snapshots to POST /api/live with the bearer token. Read GET /api/live, GET /api/v1/observations or GET /api/health. Configure the frontend with VITE_OBSERVATION_API_URL pointing to the HTTPS /api/live URL. The receiver refuses stale, oversized, older and unauthenticated writes, uses atomic file replacement, returns no-store, and serves no snapshot older than 20 minutes. If unavailable the app falls back to the published GitHub branch and packaged copy.

Road-water screening

scripts/build-exposure.py samples the midpoint of car-accessible, non-tunnel edges on the published Rotterdam DGO >25 cm model raster. It reports exposed length by simulation district. On the scenario page, selected exposed edges and a bridge are assumed closed, while rain applies an explicit wet-road speed factor. Reverse shortest-path routing estimates free-flow car time to the nearest of four sample hospitals. It does not model rainfall-to-flood dynamics, queues, ambulance priority, transport timetables, hospital capacity or safety of a journey. PDOK BGT geometry and KNMI radar nowcast remain available integration sources; neither is silently substituted for present observations.

Repeatable signal checks

Each trial arm creates a new worker with the same seed, graph, 45-second actuated warmup, time of day and target density. Only after warmup does the signal setting change. The 120-second measurement records throughput, speed, wait and a held-out NDW station-flow comparison when current observations are available. A stable 20% of stations is selected by edge hash and is never fitted in the trial. Downloaded JSON contains the configuration and per-station observed/simulated rates. This one-seed short experiment does not validate the model for operations; independent days, transit observations and authorized iVRI SPaT are needed.

Neighborhood privacy

scripts/fetch-cbs-neighborhoods.py extracts public CBS KWB 2025 totals only for municipality code BU0599. Values suppressed or missing at source remain null. No addresses, individual traces or inferred personal characteristics are published. CBS neighborhoods are displayed separately from simulation districts because their boundaries differ.
